# 🚀 Deadline Guardian

> **An AI-Powered Productivity Companion That Helps You Finish Tasks Before Deadlines Are Missed**

---

## 📌 Overview

Deadline Guardian is an AI-powered productivity companion built to solve the **"The Last-Minute Life Saver"** hackathon problem statement.

Unlike traditional reminder applications that simply notify users about upcoming deadlines, Deadline Guardian acts as an intelligent productivity partner. It proactively helps users plan, prioritize, schedule, and complete tasks before deadlines are missed.

The application leverages **Google Gemini AI** to analyze user tasks, generate personalized schedules, predict deadline risks, detect procrastination, and provide actionable productivity recommendations.

---

## 🎯 Problem Statement

**The Last-Minute Life Saver**

Students, professionals, and entrepreneurs often miss assignments, meetings, interviews, bill payments, and important deadlines because existing productivity applications rely mainly on passive reminders.

The challenge is to build an AI-powered assistant that helps users **take meaningful action** instead of simply reminding them.

---

# 💡 Our Solution

Deadline Guardian transforms productivity by introducing an **AI-powered autonomous assistant** that continuously supports users throughout the task lifecycle.

Instead of saying:

> "Assignment due tomorrow."

Deadline Guardian says:

> "Your assignment requires approximately 3 hours to complete. Starting today at 6 PM will keep you comfortably ahead of schedule."

The AI analyzes, plans, schedules, predicts risks, and continuously guides users toward successful task completion.

# 🚀 Installation

## Clone Repository

```bash
git clone https://github.com/yourusername/deadline-guardian.git

cd deadline-guardian
```

---

## Frontend

```bash
cd frontend

npm install

npm start
```

---

## Backend

```bash
cd backend

pip install -r requirements.txt

python app.py
```

---

## Environment Variables

Create a `.env` file inside the backend directory.

```env
GEMINI_API_KEY=YOUR_API_KEY

FIREBASE_API_KEY=YOUR_FIREBASE_KEY

FIREBASE_PROJECT_ID=YOUR_PROJECT_ID

SECRET_KEY=YOUR_SECRET_KEY
```
